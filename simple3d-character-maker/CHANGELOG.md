# Changelog

このプロジェクトの変更履歴を記録します。

## [0.1.0] - Phase 1 MVP（ナス専用）

### 追加

- プロジェクト初期構成（Vite + TypeScript strict + Three.js）。
- 単位・座標系規約（mm・Z-up・原点=底面中心）を `src/core/units.ts` に実装。
- データモデル（`ProjectData` 一式）と JSON バージョンマイグレーション機構。
- 断面制御点の非一様 Catmull-Rom 補間とスーパー楕円による本体表面関数
  `S(t, θ)`（`src/geometry/surface.ts`）。
- 本体メッシュ生成（`bodyMesh.ts`）: ウォータータイトな閉じたメッシュ、
  底面のフラット化、上端の1点収束。
- ヘタ（5枚の葉、`calyxMesh.ts`）・茎（`stemMesh.ts`）・目/口（`faceMesh.ts`）を
  すべて `S(t, θ)` の直接評価で生成（レイキャスト不使用）。本体の断面変更に
  自動追従する。
- 全生成モジュール共通のシェル生成ユーティリティ（`meshUtils.ts`）と、
  符号付き体積によるグローバルな巻き順補正。
- 3Dビューア（グリッド・軸・OrbitControls・正面/側面/背面/上面/斜め切替・
  平行投影・ワイヤーフレーム表示）。
- 参照画像オーバーレイと、2点クリック+実寸mm入力によるキャリブレーション。
- 単一マテリアル・単一2048×2048テクスチャアトラス方式（パーツごとの
  単色パッチ、8pxマージン）。
- 本体・ヘタ・茎・顔・色・印刷設定・プロジェクトの各パラメータUIパネル。
  スライダーはドラッグ中を1操作に畳んで Undo/Redo に積む。
- 状態管理（`ProjectStore`）: Undo/Redo（上限50段）、JSON保存・読込、
  未保存変更時の離脱確認、初期化確認ダイアログ。
- エクスポート: OBJ（`mtllib`/`usemtl` 後挿入）+ MTL、STL（バイナリ）、
  GLB（既定でmm/Z-up→m/Y-up変換、オプションでmm/Z-up維持）、
  ZIP一括ダウンロード（`model.obj`/`model.mtl`/`texture.png`/`model.glb`/
  `model.stl`/`project.json`/`print_check.txt`/`README_print.txt`）。
- 3Dプリント前検査（開発指示書6.8節の13項目）: 境界エッジ・非多様体エッジ・
  法線一貫性・縮退三角形・連結成分数・パーツ間の埋め込み深さ・茎/葉の
  最小径・モデル寸法・底面接地・原点位置・三角形数・テクスチャ有無・
  three-mesh-bvh による近似最小肉厚。パラメータ変更後500msのデバウンスと
  エクスポート直前に実行し、赤・黄・緑で表示。

### 修正

- 本体上端/底面キャップ、茎の両端キャップ、目のレンズ外周、ヘタ/口の
  境界壁において、隣接する側面クアッドと同一方向でエッジを共有しており
  法線が局所的に矛盾していた巻き順バグを修正（ウォータータイト判定のみでは
  検出できず、法線一貫性チェックの実装によって発見）。
- Undo/Redo 後にテクスチャアトラスが色の変更を反映しないバグを修正
  （色が実際に変わったときのみアトラスを再生成するよう対応）。
- 印刷検査の「モデル寸法（AABB）」が、茎を含む全体のAABBを本体単体の
  `totalHeight` と比較していたため常に不一致になっていたバグを修正し、
  本体ジオメトリ単体のAABBと比較するようにした。
