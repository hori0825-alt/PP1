# PP1 Stitch Studio v2

**Brother PP1 / Artspira 向け・ブラウザで動く刺しゅうデジタイザ**

PNG / JPG / SVG から、実機で安全に縫える刺しゅうデータ (PES / DST) を生成します。
すべての処理はブラウザ内で完結し、サーバーへのアップロードはありません。
生成した PES を Artspira アプリでインポートし、Bluetooth で PP1 へ転送して縫えます。

## PP1 Sketch — iPad で描いた絵をそのまま刺繍に (`sketch.html`)

画像を読み込んで推測で変換するのではなく、**描いた線・面がそのまま刺繍の部品になる**お絵かきアプリです。
減色や輪郭抽出をしないため、余計な色・ガタガタの輪郭・細切れの面が原理的に生まれません。

- **レイヤー = 重ね順 = 縫い順**。下のレイヤーから順に縫い、上のレイヤーが上に重なります。
  レイヤーの ↑↓ で縫う順番を入れ替えられます。
- レイヤー内は「自動順」(同じ色をまとめ、近い順・面を先に線を後に) か「描いた順」を選べます。
  縫い順タブの ↑↓ で個別の順番も変更できます。
- 道具: ペン (太さで ランニング / 3重ぬい / サテン を自動選択)、バケツ塗り (線で囲まれた内側をタップ。
  手描きの小さな隙間は自動で閉じ、塗りは線の下に潜り込ませて隙間を防ぐ)、塗りペン (囲んだ形を塗る)、
  円・四角、選択/移動、消しゴム。糸色は Brother 64 色から選ぶので PES に色がそのまま残ります。
- 糸切り: 1つの線・面の中では切らない。後で縫う面の下に隠れる渡りはつなぎ縫い、隠れない渡りは
  距離に応じて渡り糸か糸切り (設定で「少なく」「渡り糸を残さない」も選択可)。
- iPad: Apple Pencil で描く (Pencil を検出すると指は移動・拡大専用になる)、2 本指ピンチで拡大、
  2 本指タップで取り消し・3 本指タップでやり直し。ホーム画面に追加すると全画面で使えます。
  作業は自動保存されます。
- 下敷きの画像 (v1.2): 🖼 下絵 ボタンで写真・イラストを一番下のレイヤーに入れ、その上のレイヤーでなぞって描ける。
  画像は選択ツールで移動・拡大縮小・回転・反転でき、濃さも変えられる。画像は縫われない。
  画像データは端末内 (IndexedDB) に保存され、「作品を保存」の .json にも埋め込まれる。
- PES を開いて修正 (v1.3): 「作品・PES を開く」で PES を読み込める。このアプリで書き出した PES には
  編集用データ (線・面・レイヤー・設定) が入っていて、描いたときの状態に戻る (下絵の画像は入らない)。
  編集用データは PES のラッパー部分 (PEC の前) に置くので、刺繍機・Artspira が読むステッチは変わらない
  (設定でオフにもできる)。他のソフトの PES や編集用データのない PES は、針の並び方から
  線・面を推定して戻す (サテン → 太さ付きの線、3重ぬい → 3重の線、ランニング → 細い線、
  タタミ → 面 (穴・縫い角度も)。下縫い・つなぎ縫い・止め縫いは除く)。推定できない部分は
  「縫い目」のまま残し、移動・拡大縮小・回転・色・針の位置を編集できる (コードは `src/sketch/reconstruct.ts`)。
- キャンバスのサイズ (v1.2): 100×100 (PP1 最大)・正方形・横長・縦長のプリセットか mm 指定で選べる。
  変更時に描いた絵を合わせて拡大縮小することもできる。PP1 の枠 (100mm) を超えると点線で範囲を表示して警告。
- 刺繍プレビューで縫う順番を再生し、糸切り位置 (赤 ✕) と渡り糸 (点線) を確認してから PES / DST を保存。
- 描いた後の修正 (v1.1): 選択ツールでタップ選択・範囲選択・追加選択。選択枠の角で拡大縮小 (縦横比固定)、
  辺で縦/横だけ伸縮、○ハンドルで回転 (15° に吸着)、ドラッグで移動。コピー・切り取り・貼り付け・複製、
  左右/上下反転、90° 回転、パネルで大きさを mm 指定。
- 編集点ツール: 点をドラッグで変形 (「やわらか」で周りの点も滑らかについてくる)、線の上をタップで点を追加、
  点を削除、間引く / 増やす、線を閉じる / 開く。キーボード (⌘C/X/V/D/A・Delete・矢印) にも対応。
- 画面いっぱいに描ける: レイヤー・縫い順・設定は ☰ で開く引き出しになり、刺繍枠は画面の最大サイズで表示。
  ⛶ で全画面 (iPad Safari)。縦向きでも描く場所を広く取ります。

コードは `src/sketch/` (モデル・コンパイラ・バケツ塗り・修正操作 `edit.ts`・UI)。ステッチ生成と PES/DST 出力は本体と共通です。

## 設計の最優先事項

前バージョンでは「少し縫ってすぐ糸を切る」データになり実機で使えませんでした。
v2 はこの問題を**データ構造のレベルで根絶**することを最優先に再設計しています。

- ステッチの中間表現は「色ブロック → 連続ステッチ列 (Run)」の2層のみ。
  **糸切りは Run と Run の間の属性としてしか存在できず**、ステッチ列の途中に
  糸切りを差し込む手段がコード上に存在しません。
- 1つの面 (フィル領域) は必ず1本の連続した Run として生成されます。
  穴や凹みで走査が分断される場合も、領域の縁に沿った移動ステッチ
  (Travel on Edge) でつなぎ、面の途中で糸を切りません。
- 同色の近接オブジェクトは縁沿い移動で接続し、糸切りは「離れた領域への
  10mm 超の移動」だけに限定します。

### v3.22.0 のエンジン改善 (ロゴ・線画の品質)

- **面内糸切りの完全根絶**: タタミが連結成分ごとに Run を分けていた不具合を修正。
  走査線の隙間で面が分断されても、必ず1領域=1連続 Run に統一。
- **線画 (SVG stroke) 対応**: `fill="none"` の線パスを太さで囲んだリボン領域に
  変換し、アニメ絵・ロゴのアウトラインを縫えるようにしました。
- **角を保存する平滑化**: ロゴの直角・文字のセリフが丸まらないよう、鋭い屈曲は
  固定して曲線部だけを平滑化します。
- **サテン密度 0.35mm / 分岐形状の確実なフォールバック**で輪郭・文字が締まります。
- **出力前の安全網**: 面内糸切り (error)・長い渡り糸 (warning) を検出。サイズの
  自動縮小は既定で無効 (寸法を勝手に変えない)。

## 対応と制約 (Brother PP1 / Artspira)

- 刺繍範囲: 最大 100mm × 100mm
- 出力: PES (糸色を Brother 64色パレットで保持) / DST
- 針数上限: 12,000 針 (超過時は警告 + 自動削減)

## 使い方

```bash
npm install
npm run dev       # http://localhost:5173 で UI を起動
npm run test      # 全テスト (326件)
npm run build     # 型チェック + 本番ビルド
npm run samples   # 実機テスト用サンプルを samples/ に生成
```

### 操作フロー

1. **デザイン**タブで画像 (PNG/JPG) または SVG を読み込み、サイズを選ぶ
   (10/7/5/3/2cm)。自動で減色 → ベクター化 → 刺しゅう化されます。
2. **色**タブで色数 (2〜15) と白背景除去を調整。
3. **ステッチ**タブ (プロモード) で角度・下縫い・糸切りモードを設定。
4. **縫い順**タブ (プロモード) のシーケンスビューで縫製順・糸切り箇所を確認。
   キャンバス下のシミュレーターで実際の縫い順を再生できます。
5. **診断**タブで OK / 注意 / 修正必須を確認。針数超過はワンクリックで自動削減。
6. **出力**タブで PES / DST をダウンロード。プロジェクト (.json) も保存できます。

### かんたんモード / プロモード

- **かんたん**: デザイン → 色 → 診断 → 出力 → ライブラリ の最短フロー。
- **プロ**: + ステッチ詳細 / ベクター(ノード)編集 / 文字 / 縫い順編集 /
  布地レシピ / 特殊 (装飾配置・アップリケ・3D パフィー) / 診断。

### 主な機能

- 画像/SVG デジタイズ、写真刺繍 (PhotoStitch、明暗→密度、12,000針制限)
- タタミ/サテン/ランニング/下縫い、Pull/Push 補正、布地別レシピ
- 縫い順最適化 (Closest Join)・Travel on Edge・Branching で糸切り最小化
- ベクター/ノード編集 (corner/smooth・Snap to Artwork)
- 文字刺繍 (横書き/縦書き/円弧、サテン/タタミ、品質警告)
- 装飾配置 (ミラー/放射/万華鏡)、アップリケ工程、3D パフィー
- シーケンスビュー、ステッチシミュレーター、出力前診断
- 作業指示書 PDF (印刷)・QR コード・プレビュー画像、デザインライブラリ

## AI 解析 (v3.21.0〜)

画像を AI で解析し、減色・ベクター化・ステッチ化の設定を自動提案します。

### セキュリティ

- API キーはフロントエンド (HTML/JS/localStorage/URL) に **一切含まれません**
- API キーはバックエンド (Vercel Edge Functions) の環境変数でのみ管理します
- フロントエンドは `/api/embroidery-ai` に POST し、解析結果の JSON だけを受け取ります

### 2つのモード

| モード | 説明 | 要件 |
|---|---|---|
| おまかせ設定 (オフライン) | パーツ形状から設定を即座に計算 | なし (常に利用可) |
| AI 解析 (サーバー経由) | OpenAI GPT-4o で画像を詳細解析 | Vercel デプロイ + API キー |

### デプロイ方法

#### A. Vercel にデプロイ (推奨: フロントエンド + AI)

1. Vercel にリポジトリを接続
2. 環境変数を設定: `OPENAI_API_KEY=sk-...` / `OPENAI_MODEL=gpt-4o` (省略可)
3. デプロイ (`api/embroidery-ai.ts` が Edge Function として自動認識)

#### B. GitHub Pages + Vercel API (分離構成)

1. Vercel に同リポジトリを接続し環境変数を設定
2. GitHub Pages 側のビルド時: `VITE_AI_API_URL=https://your-project.vercel.app npm run build`

#### 環境変数

| 変数名 | 設置場所 | 説明 |
|---|---|---|
| `OPENAI_API_KEY` | Vercel 環境変数 | OpenAI API キー (バックエンド専用) |
| `OPENAI_MODEL` | Vercel 環境変数 | 使用モデル (省略時 `gpt-4o`) |
| `VITE_AI_API_URL` | ビルド時環境変数 | AI バックエンドの URL (分離構成時のみ) |

`.env.example` → `.env` にコピーしてローカル開発に使えます。`.env` は `.gitignore` に含まれています。

## アーキテクチャ

責務を分離し、コアロジックは DOM 非依存でテスト可能です。

```
src/core/      型定義 (StitchPlan)・定数・幾何・プロジェクト保存
src/import/    画像読込・色数削減 (Lab k-means)・領域抽出・SVG パース
src/stitch/    ステッチ生成 (タタミ/サテン/ランニング/下縫い)・スキャンライン
src/plan/      縫い順最適化・糸切り判定・Branching・診断・統計・自動削減
src/export/    PES/DST 書き出し・読み戻し・バリデーション・SVG プレビュー
src/ui/        UI (状態管理・キャンバス・シーケンスビュー・シミュレーター)
src/samples/   実機テスト用サンプル定義
```

将来フォーマット (JEF/EXP/VP3 等) は `src/export/` に Exporter を追加するだけで
拡張できます。内部ステッチ表現 (StitchPlan) は1つに統一されています。
